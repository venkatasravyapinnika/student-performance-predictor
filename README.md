
# Student Performance Predictor

A machine learning project that predicts a student's final grade using previous grades and other academic information.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Joblib
- Streamlit

## Features
- Takes student details as input
- Predicts the final grade out of 20
- Displays the equivalent percentage
- Shows a bar chart comparing grades

## How to Run

1. Install the required libraries:
   pip install -r requirements.txt

2. Train the model:
   python train_model.py

3. Start the application:
   streamlit run app.py
